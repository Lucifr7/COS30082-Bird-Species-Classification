# Bird Species Classifier

ConvNeXt-Tiny fine-tuned on CUB-200 (200 bird species) for COS30082 Assignment 1.
Upload a bird photo to get the top-5 species, a Grad-CAM heatmap showing where the network
looked, and a reference photo of the predicted species.
